# OCR Token Line Clustering Design

## Goal

같은 줄의 문자열이 여러 OCR 박스로 분리되었을 때 박스 좌표의 미세한 차이로
문자열 순서가 흐트러지는 문제를 해결한다. 박스 평균 형태와 선택 이미지의
방향을 함께 사용해 토큰을 줄 단위로 묶고 올바른 방향으로 읽는다.

## Alternatives Considered

### Fixed Pixel Tolerance

두 박스의 `x` 또는 `y` 차이가 고정 픽셀 이내이면 같은 줄로 판단할 수 있다.
구현은 단순하지만 contact sheet 확대 비율과 원본 이미지 크기에 따라 적절한
임계값이 달라지므로 사용하지 않는다.

### Center Distance Relative to Average Size

박스 중심점 간 거리를 평균 높이나 폭과 비교할 수 있다. 크기가 크게 다른
박스가 섞이면 중심점 차이가 커져 실제 같은 줄을 분리할 가능성이 있다.

### Interval Overlap Ratio

가로줄은 세로 구간, 세로줄은 가로 구간의 겹침 정도를 비교한다. 짧은 쪽
박스 구간의 50% 이상이 겹치면 같은 줄로 판단한다. 박스 크기와 확대 배율에
비례하고, 같은 줄의 작은 위치 흔들림을 직접 흡수하므로 이 방식을 사용한다.

## Box Shape Classification

현재 방향 이미지별 평균 박스 형태 판정을 유지한다.

- 평균 폭이 평균 높이보다 크거나 같으면 가로형 박스로 판단한다.
- 평균 폭이 평균 높이보다 작으면 세로형 박스로 판단한다.
- 박스가 없으면 빈 결과를 반환한다.

가로형 박스는 가로줄로, 세로형 박스는 세로줄로 그룹화한다. 한 방향 이미지
안에서는 모든 토큰에 동일한 평균 형태 판정을 적용한다.

## Same-Line Classification

### Horizontal Lines

두 박스의 세로 구간 `[y, y + height]`을 비교한다. 겹친 길이를 두 박스 중
더 짧은 높이로 나눈 값이 `0.5` 이상이면 같은 가로줄로 본다.

### Vertical Lines

두 박스의 가로 구간 `[x, x + width]`을 비교한다. 겹친 길이를 두 박스 중
더 짧은 폭으로 나눈 값이 `0.5` 이상이면 같은 세로줄로 본다.

줄 그룹은 입력 annotation 순서에 영향을 받지 않도록 연결 요소 방식으로
만든다. 모든 박스 쌍에 대해 50% 겹침 여부를 계산하고, 같은 줄인 쌍 사이에
연결을 만든다. 직접 또는 다른 박스를 거쳐 연결된 토큰들을 하나의 줄로
묶는다. 이를 통해 같은 줄에서 박스 위치가 점진적으로 조금씩 움직이는
경우에도 중간 박스를 통해 한 줄로 유지된다.

각 줄의 대표 위치는 포함된 박스 중심 좌표의 평균으로 계산한다. 가로줄은
평균 세로 중심을 기준으로 위→아래, 세로줄은 평균 가로 중심을 기준으로
왼쪽→오른쪽 정렬한다.

## Reading Order

### `upright`

- 가로형: 가로줄을 위에서 아래로 정렬하고, 각 줄 안은 왼쪽에서 오른쪽으로
  읽는다.
- 세로형: 세로줄을 왼쪽에서 오른쪽으로 정렬하고, 각 줄 안은 위에서 아래로
  읽는다.

### `rotated_ccw_90`

- 가로형: 가로줄을 위에서 아래로 정렬하고, 각 줄 안은 왼쪽에서 오른쪽으로
  읽는다.
- 세로형: 세로줄을 왼쪽에서 오른쪽으로 정렬하고, 각 줄 안은 아래에서
  위로 읽는다.

주 정렬 좌표가 같은 경우 나머지 좌표를 보조 키로 사용한다. 두 좌표까지
같은 경우 Python의 안정 정렬이 원래 annotation 순서를 유지한다.

## Architecture

`app/analysis/ocr/ocr_processing.py`의 기존
`_sort_tokens_by_average_box_shape`를 방향 정보를 받는 줄 클러스터링 정렬로
확장한다.

```python
def _sort_tokens_by_average_box_shape(
    tokens: list[dict[str, Any]],
    orientation: str,
) -> None:
```

내부에는 다음 책임을 가진 작은 순수 헬퍼를 둔다.

- 두 1차원 구간의 짧은 구간 기준 겹침 비율 계산
- 박스 쌍의 동일 줄 여부 판정
- 동일 줄 관계의 연결 요소를 이용한 가로줄 또는 세로줄 그룹 생성
- 이미지 방향과 박스 형태에 맞는 줄 내부 정렬

`map_ocr_result_to_rows`는 각 variant의 `orientation`을 정렬 함수에 전달한다.
정렬된 토큰 목록으로 기존과 동일하게 `text`, 평균 confidence, 적격 여부를
계산한다.

## Data Flow

1. OCR annotation을 방향 이미지에 매핑한다.
2. 방향별 평균 폭과 평균 높이로 가로형 또는 세로형을 결정한다.
3. 가로형은 세로 구간, 세로형은 가로 구간의 50% 겹침으로 줄을 만든다.
4. 줄들을 위→아래 또는 왼쪽→오른쪽으로 정렬한다.
5. 줄 안의 토큰을 선택 이미지 방향에 맞게 정렬한다.
6. 평탄화된 토큰 목록으로 OCR 텍스트와 confidence 표시 순서를 만든다.

## Edge Cases

- 토큰이 없으면 아무 작업도 하지 않는다.
- 토큰이 하나이면 하나의 줄로 유지한다.
- 폭 또는 높이가 0인 박스는 겹침 비율의 분모가 0이므로 다른 박스와 같은
  줄로 판정하지 않으며, 자체 줄에 배치한다.
- 평균 폭과 평균 높이가 같으면 가로형으로 처리한다.
- 알 수 없는 orientation은 `upright`와 같은 순서를 사용한다.
- 50% 겹침은 포함 경계이므로 정확히 `0.5`인 경우 같은 줄이다.

## Testing

`tests/test_ocr_processing.py`에 다음 회귀 테스트를 추가한다.

- 높이가 조금 다른 가로형 박스들이 50% 이상 겹치면 같은 가로줄로 묶이고
  왼쪽→오른쪽으로 정렬된다.
- 세로 겹침이 50% 미만인 가로형 박스들은 서로 다른 줄로 유지되고 줄은
  위→아래로 정렬된다.
- 폭이 조금 다른 세로형 박스들이 50% 이상 겹치면 같은 세로줄로 묶인다.
- `upright` 세로줄 내부는 위→아래로 정렬된다.
- `rotated_ccw_90` 세로줄 내부는 아래→위로 정렬된다.
- 여러 가로줄과 여러 세로줄에서 줄 순서와 줄 내부 순서를 함께 검증한다.
- 정확히 50% 겹치는 경계 사례가 같은 줄로 묶이는지 검증한다.
- 전체 테스트로 최소 3토큰 필터, 방향 선택, confidence 번호, 파이프라인
  필터링이 유지되는지 확인한다.

## Scope

이번 변경에는 OCR 토큰 매핑, 최소 토큰 적격 기준, 평균 confidence 선택,
contact sheet 생성, 디버그 렌더링 레이아웃 변경이 포함되지 않는다.
